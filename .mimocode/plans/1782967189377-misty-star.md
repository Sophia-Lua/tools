# Plan: 移除配置文件功能，增加模型选择

## 目标
1. 移除所有 profile（配置文件）相关功能
2. 新增 AI 模型 ID 自由输入（文本框），替代硬编码的 `google/gemini-2.0-flash-001`

## 修改文件清单

### 1. `popup.html` — 移除 profiles 区块，新增模型输入框
- 删除第 18-24 行的 `.profiles` 区块（配置文件选择 + 管理按钮）
- 在 API 密钥设置区域下方新增模型 ID 输入框 + 保存按钮

### 2. `popup.js` — 移除 profile 逻辑，新增 model 逻辑
- 删除 profile 相关变量（`profileSelect`, `manageProfilesBtn`）和加载逻辑
- 删除 `manageProfilesBtn` 的 click 事件监听
- 新增 `modelInput` / `saveModelBtn` 的 DOM 引用
- 加载时从 `StorageUtils.getModel()` 读取并填充
- 保存时调用 `StorageUtils.saveModel()`
- `getSuggestionsBtn` 点击时不再需要选择 profile，改为直接从 storage 读取 model（或传给 background）
- 由于不再有 userData，`getFillSuggestions` 改为只传 fields，AI 通过 prompt 自行推断填写内容

### 3. `background.js` — 更新 API 调用逻辑
- `getFillSuggestions` 消息处理：不再接收 userData，只传 fields
- `handleOpenRouterCall` 中 `model` 字段从硬编码改为从 `StorageUtils.getModel()` 动态读取

### 4. `utils/storage.js` — 移除 profile 方法，新增 model 方法
- 删除 `getProfiles()`, `saveProfile()`, `deleteProfile()`
- 新增 `getModel()` / `saveModel()`，存取 `chrome.storage.local` 中的 `model` key
- 保留 `getApiKey()`, `saveApiKey()`, `deleteAll()`

### 5. `utils/ai-filler.js` — 简化 prompt 构建
- `getFillSuggestions(fields)` 不再接收 userData
- `buildPrompt(fields)` 只包含表单字段信息，提示 AI 根据字段名/type/label/placeholder 生成合理的填充值
- `parseResponse` 不变

### 6. 删除文件
- `popup-profiles.html`
- `popup-profiles.js`

### 7. `manifest.json` — 清理 web_accessible_resources
- 移除 `popup-profiles.html` 资源声明

### 8. `popup.css` — 清理样式
- 移除 `.profiles` 相关样式
- 移除 `.profile-form`, `#save-profile-btn`, `#back-btn`, `.profile-item`, `.delete-btn` 样式
- 更新 `#save-key-btn` 的选择器（移除 `#manage-profiles-btn`）

### 9. 测试更新

#### `tests/utils/storage.test.js`
- 删除 profile 相关测试（4 个 case）
- 新增 `getModel` / `saveModel` 测试

#### `tests/background.test.js`
- 更新 mock：storage mock 增加 `getModel`
- 更新 `getFillSuggestions` 测试：不再传 userData
- 更新 `callOpenRouter` 测试：body 中 model 字段改为动态读取值

#### `tests/integration.test.js`
- 更新集成测试：移除 userData 传入，修改 ai-filler 调用方式

#### `tests/compatibility.test.js`
- `web_accessible_resources` 测试：移除对 popup-profiles.html 的断言

#### `tests/setup.js` — 无需修改

## 验证步骤
1. `cd chrome-extension-auto-fill && npm test` — 所有测试通过
2. 手动加载插件到 Chrome：`chrome://extensions` → 开发者模式 → 加载已解压扩展程序
3. 打开 popup：验证 API 密钥输入 + 模型 ID 输入框正常显示
4. 输入模型 ID 保存后刷新 popup，验证持久化
5. 打开含表单的页面，点击"检测表单"→"获取AI建议"，验证使用自定义模型 ID 调用 API
